PIXELDUNIYA — CONTENT UPDATE
============================

This update adds 10 new original sample items to the website:
- 2 wallpapers
- 2 animated GIFs
- 2 icons
- 2 emojis
- 3 stickers/graphics

HOW TO UPDATE THE LIVE WEBSITE
1. Download and extract this ZIP.
2. Open your GitHub repository named pixelduniya.
3. Choose Add file -> Upload files (or the empty-repository upload link).
4. Upload the updated index.html and all files from the assets folder.
5. Keep index.html in the repository root and the assets folder beside it.
6. Commit changes to main, then wait for GitHub Pages to deploy.

IMPORTANT
- Upload extracted files, not the ZIP itself.
- If asked to replace index.html, confirm.
- These are original sample assets made for this starter project.
- This is a static website; it does not yet have an admin panel/database.
