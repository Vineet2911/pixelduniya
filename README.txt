PIXELDUNIYA — FREE WEBSITE STARTER
=================================

This is a static starter website for a downloadable visual library:
wallpapers, GIFs, icons, emojis and stickers.

FILES
- index.html: page content
- styles.css: responsive styling
- script.js: category filtering, search, sorting and downloads
- assets/: original demo assets used by the sample cards

IMPORTANT
- This is a starter/demo site, not yet a fully managed production platform.
- The sample assets are original demo files created for this project.
- Before publishing, replace/add only content you own or have permission to distribute.
- Add a contact page, privacy policy, terms, and clear content/licensing information before applying for ad monetization.
- Free hosting plans have limits; check current provider terms before launch.
- Download buttons work best when opened through a local server or a published website, not directly from file://.

RUN LOCALLY (EASIEST)
1. Extract the ZIP to a folder.
2. Open the folder in VS Code.
3. Install the VS Code extension "Live Server" (optional).
4. Right-click index.html and choose "Open with Live Server".
   Alternative if Python is installed: open a terminal in this folder and run:
   python -m http.server 8000
   Then visit http://localhost:8000
